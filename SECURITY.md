# Security Policy

## Reporting Security Vulnerabilities

We take security and edge network integrity seriously. If you discover a vulnerability in PyCDN:

1. **Email:** Please report all security vulnerabilities to `yashpatadiya1724@gmail.com`.
2. **Details:** Include reproduction steps, affected components (origin, edge, or load balancer), and impact assessment.
3. **Response:** You will receive an acknowledgment within 48 hours.
4. **Responsible Disclosure:** Please do not open public issues regarding unpatched security vulnerabilities.
